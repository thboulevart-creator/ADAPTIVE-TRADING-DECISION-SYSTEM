## 2. Clarification sur l'ancien énoncé d'audit

Les noms `02-ARCHITECTURE.md` et `03-DECISION-FLOW.md` ne correspondent pas aux fichiers actuellement présents dans le dépôt.

Ils ne doivent donc plus être utilisés pour désigner le corpus réel sans référence explicite à une version historique ou à une proposition externe.

L'audit et les analyses futures doivent utiliser les noms de fichiers réels ci-dessus.

## 3. Portée

Cette clarification ne prétend pas déterminer si `02` et `03` remplacent historiquement d'autres documents. Elle fixe uniquement la nomenclature du dépôt réel à utiliser pour la suite.
