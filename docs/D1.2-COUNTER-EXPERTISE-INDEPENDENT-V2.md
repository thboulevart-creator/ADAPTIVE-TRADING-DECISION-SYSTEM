# 2. Verdict indépendant

**CONTRE-EXPERTISE : AUDIT V2 GLOBALLEMENT CONFIRMÉ, AVEC DEUX NUANCES IMPORTANTES.**

### Nuance 1 — provenance B2

Le défaut de provenance B2 est réel pour un auditeur externe du dépôt, mais il ne prouve pas que l'arbitrage B2 n'existe pas. Il prouve seulement que **le dépôt ne permet pas actuellement de le vérifier de manière autonome**.

Il faut donc corriger la matrice sans réécrire l'historique :

```text
B2 établi dans le processus
≠
B2 vérifiable dans le dépôt
```

La bonne correction est une qualification de provenance, pas une suppression artificielle de B2.

### Nuance 2 — « exigence inventée »

Une traduction D1 candidate n'est pas une exigence inventée si elle est explicitement marquée candidate et si elle reste nécessairement soumise à arbitrage.

Le risque d'invention apparaît lorsque la phrase est placée dans **Exigence héritée** ou dans **B2 établi** sans source suffisante.

# 4. Contre-test « B2 établi »

Le test le plus sévère donne trois catégories :

### A — Directement vérifiable dans `04`

Les éléments suivants peuvent rester hérités si la source et la formulation sont conservées :

- séparation exploratoire / confirmatoire ;
- Charter avant confirmation ;
- Charter datée/horodatée ;
- gel et amendement ;
- falsifiabilité ;
- justification économique/comportementale ;
- frontières confirmatoires ;
- gel technique ;
- budget d'hypothèses ;
- taille d'échantillon ex ante ;
- unité statistique ;
- spécification du test ;
- direction pré-enregistrée ;
- spécification des contrôles ;
- distinction falsification / essai non interprétable ;
- reproductibilité par deux analystes indépendants ;
- règle cardinale `règle → condition → conséquence → procédure → traçabilité`.

### B — Héritage de gouvernance D1 à arbitrer

- acteurs et autorités ;
- séparation des rôles ;
- arbitrage des contradictions ;
- indépendance IA.

Ces éléments sont justifiés par les findings et interfaces de gouvernance, mais **ne doivent pas être rétro-présentés comme des citations B2**.

### C — Garde-fous de processus

- non-réouverture CTR-01/02 ;
- absence d'adoption implicite de `05`.

Ils doivent rester visibles, mais séparés de l'héritage méthodologique B2.

# 5. Contre-test de circularité

Le risque majeur est confirmé :

```text
Règle D1
  ↓
autorité D1
  ↓
validation de la règle D1
  ↓
preuve de conformité
```

Cette chaîne ne constitue pas une preuve indépendante.

**Conclusion :** D1.3 devra traiter l'indépendance de l'autorité de contrôle comme une question de gouvernance explicite, mais D1.2 ne doit pas inventer la solution.

---

# 6. Contre-test des critères

Les critères de D1.2 doivent être répartis en trois catégories :

1. **preuve de traçabilité** — la chaîne documentaire est vérifiable ;
2. **preuve de conformité procédurale** — le protocole a été respecté ;
3. **preuve scientifique/statistique** — l'hypothèse a été testée selon le protocole.

Une preuve de catégorie 1 ou 2 ne doit jamais être décrite comme preuve de catégorie 3.

La matrice actuelle mélange encore parfois ces niveaux dans « Critère + preuve attendue ».

**Correction minimale recommandée :** qualifier les preuves, sans ajouter de nouvelle exigence normative.
