## 5. External platform classification

Microsoft's Windows reparse-tag specification identifies:

    IO_REPARSE_TAG_CLOUD_6 = 0x9000601A

as a Cloud Files filter tag used for files managed by a synchronization engine such as OneDrive.

This platform classification does not itself qualify the local Vault.

It only justifies replacing the old generic "all reparse points forbidden" assumption with a bounded, native-tag-aware candidate policy.

## 6. P3-C2 policy decision candidate

Candidate acceptance is deliberately narrow.

For regular files only, the P3-C2 allowlist is:

    NO_REPARSE_POINT
    IO_REPARSE_TAG_CLOUD_6 / 0x9000601A

Still prohibited:

- any other reparse tag;
- symlink;
- junction;
- mount point;
- directory reparse point;
- offline state;
- sparse state;
- unreadable state.

Cryptographic equality remains mandatory.

A Cloud Files tag never substitutes for SHA-256, deterministic projection-tree identity, integrity-manifest verification, or fresh P2 reconstruction.
