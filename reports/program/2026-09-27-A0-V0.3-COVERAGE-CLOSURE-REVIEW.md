## Review method

This review is conservative.

A V0.3 requirement is considered coverage-closed only when at least one of the following exists:

1. a persisted executable test that would fail if the required property were removed or the forbidden mutation were accepted; or
2. for an ordering/governance-only requirement, persisted chronological evidence that directly proves the required ordering/freeze.

The mere fact that the current implementation contains a field or behavior is not treated as sufficient qualification evidence.
